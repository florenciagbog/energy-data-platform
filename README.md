# Energy Data Platform

## Overview

This project builds a cloud-native data platform that automatically ingests daily electricity generation data from the U.S. Energy Information Administration (EIA) API, transforms it into analytics-ready datasets, and serves business insights through Streamlit and Power BI.

## Business Problem

The Analytics team requires a centralized and automated source of electricity generation data for reporting and historical trend analysis. The current manual process is time-consuming and does not preserve historical records.

## Technology Stack

- Python
- Google Cloud Platform
- BigQuery
- Cloud Run
- Cloud Scheduler
- dbt
- Streamlit
- Power BI
