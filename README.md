# Energy Data Platform

## Overview

This project simulates a real-world Data Engineering initiative to automate the ingestion of external electricity generation data from the U.S. Energy Information Administration (EIA).

The solution is built on Google Cloud Platform and follows a modern analytics architecture using BigQuery, dbt, Streamlit and Power BI.

## Business Problem

The Analytics team requires a centralized and automated source of electricity generation data for reporting and historical trend analysis. The current manual process is time-consuming and does not preserve historical records.

## Technology Stack

- Python
- Google Cloud Platform
- BigQuery
- Cloud Run
- Cloud Scheduler
- dbt
- Streamlit
- Power BI
